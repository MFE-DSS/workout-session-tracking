# DA09-C — mémoire native acceptée

## Why
La mémoire historique native doit distinguer faits, prescription, provenance et accès indisponible dans une lecture instrumentale compacte. DA09/G1 C est déjà autorisé ; les pixels finaux du 24 novembre sont explicitement acceptés.

## What Changes
Extraction de livraison du seul consommateur C depuis le travail DA09 B/C préservé : semaines factuelles bornées, séries typées compactes et poids daté sélectionnable avec équivalent TalkBack. Pas de nouvelle exploration, primitive ou calcul scientifique. B/A restent hors PR et hors acceptation.

## Impact
Neuf fichiers produit/test dans clients/mobile/src/ui/history seulement. Aucun backend, route, DTO, compte, horloge, stockage, dépendance, baseline ou déploiement. Les autorités et leurs références ne sont pas modifiées : l’inventaire réel joint couvre 169 fichiers. Un change de livraison C = une PR, puis archive C ; le dossier DA09 global et B sont préservés sans fausse clôture.
