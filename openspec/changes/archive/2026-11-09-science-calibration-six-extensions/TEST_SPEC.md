# Vérifications à implémenter après GO — aucune exécution produit revendiquée

| Cas | Attendu depuis vrai moteur/validateur |
|---|---|
| Chaque ID des six, zéro épisode/setting | Aide/acquisition disponibles ; aucun septième prérequis, pas kg ou essai chargé inventé |
| Chaque réalisation avec préparation/choix/contexte/familiarisation chargée/essai/acceptation actuels | QUALIFIED provisoire, références exactes, épisode portable |
| RDL sans haltères / seulement rehearsal | Pas ATTEMPT_OBSERVED ou setting0 synthétisé ; pas essai/qualification |
| Familiarisation None ou autre setting, booléen trial.familiarization_confirmed True seul | Refus d'offre d'acceptation et de qualification malgré diagnostic C3 éventuellement CALIBRATED |
| Choix/setup/context avant/après essai, saisie tardive réellement antérieure | Temps réel et contexte applicables vérifiés sans réécrire l'histoire |
| G17 fixe/wide/pronation ou autre ref, mollets assis, rowing sans appui | Pas de promotion sous le nom du candidat ; scope exact fermé |
| MACHINE vs PER_IMPLEMENT ; autre unité/côté/appareil/sémantique | Pas transfert ni conversion ou admission du profil non couvert |
| Voluntary stop/time limit réel sans préoccupation | Observation, pas failure inventé ni qualification ; retry humain explicite seulement sous conditions |
| False/CONCERN/UNKNOWN, ledger incomplet, prédécesseur bloqué, retrait | Pas nouveau guidage ou contournement par ID/date fraîche |
| Ancien fait qualifié puis choix courant absent | Historique lisible ; absence de permission actuelle distincte, aucun fait effacé |
| Autorité caller/digest falsifié, source dérivée, publication inactive, source modifiée | Refus fermé ; preview/fixture ne sert pas de fallback |
| Bool/NaN/Infinity/instances Pydantic copies non validées | Validation stricte, aucun bool=nombre |
| Six résultats + pilote, vrai loader/producteur/validation V3 | SCI prêt limité, temps UNKNOWN, REQUIRES_TIME_ACK ; ack exact synthétique étiqueté →ELIGIBLE isolé |
| Un épisode manquant, ancien accepté réimporté ou ack périmé | V3 refuse sous ses propres gates, sans modifier son validateur |
| Anciens sources/export/outputs | Hashes et replay inchangés ; nouveaux exports reproductibles dans leur répertoire |
