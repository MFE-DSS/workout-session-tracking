## Brainstorming / Options / Risques / Choix retenu

Choix de préparation : inventaire complémentaire lisible/machine, sources exactes et slices minces de consommation du domaine existant ; nutrition manuelle explicitement nouvelle. ## Evidence model

`docs/pilot/pilot-parity-00/capabilities.v1.json` est la source structurée ; MATRIX.md en est la projection de revue. Chaque ligne porte les douze champs du mandat et le statut du build installé. Les statuts désignent cette capacité, pas la maturité globale du produit. SERVED_NATIVE exige preuve sur build cible ; câblage réel mais recette incomplète = PARTIAL. DOMAIN_ONLY = domaine/web sans équivalent natif ; NOT_IMPLEMENTED = chaîne runtime non trouvée dans le périmètre cherché ; BLOCKED nomme un contrat/donnée/permission ; OUT_OF_CORE n'est pas un prétexte pour ignorer un besoin critique confirmé du pilote.

Les priorités P0/P1/P2 sont des propositions à partir du mandat, avec autorité explicite distincte d'une observation de captures. Les sources positives ont des ancres ; une absence repose sur une recherche bornée explicitée dans SOURCE_NOTES.md, jamais un faux numéro de ligne. Un lien web ou galerie ne remplit pas le critère de fonction native. Le calendrier daté n'existe pas dans WeeklyPlan indexé ; la qualité sommeil1–5 n'est pas une durée capteur ; la masse musculaire balance n'est pas un tissu mesuré.

## Visual, import and privacy

Quatre familles à soumettre quand leur scope est prêt : MISSION/orientation (cartes LOCKED conservées), historique entraînement, acquisition/chronologie corporelle et journal nutrition manuel. Les primitives de charts sont partagées lorsque leur contrat convient ; données/unités propres restent séparées. Une planche consolidée par famille, pas par exercice/écran/mesure. G1 avant composition, vrais pixels iOS/Android avant commit UI. Pas de vert, cinquième onglet, score, raster de graphique ou anatomie ajoutée.

IMPORT_DISCOVERY.md borne un futur import à des exports effectivement disponibles, propriétaire résolu, unités/dates non ambiguës, preview et commit idempotent de lignes revues. PDF→brouillon seulement. Aucune donnée personnelle, sauvegarde source ou appel LLM n'est collecté dans cette préparation ; politique/finalité/source/droits/stockage/rétention à admettre avant opération réelle. DATA existant n'autorise pas implicitement nutrition, santé ou documents.
