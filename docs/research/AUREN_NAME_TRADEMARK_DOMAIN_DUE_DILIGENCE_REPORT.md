## 1. Résumé exécutif

Le screening préliminaire du nom **AUREN** pour une application logicielle de suivi d'entraînement
(marché initial FR/CH/UE, PWA, non médical) aboutit à **BLOCKED FOR PROFESSIONAL CLEARANCE** pour
**deux raisons cumulatives** :

1. **Axe domaine — défavorable et vérifié** : **tous** les domaines prioritaires audités par RDAP
   sont **déjà enregistrés** — `auren.com/.net/.org/.fr` (cluster OVH établi depuis 1998–2011),

   (`getauren.com`, `useauren.com`, `aurenapp.com`, `aurenfitness.com`, créés 2025–2026). Aucun
   candidat primaire ni fallback évident n'est libre. Une stratégie domaine cohérente n'est **pas**
   démontrable en l'état — ce qui **exclut le PRELIMINARY GO** (qui exige une « stratégie domaine
   viable »).
2. **Axe marque — données insuffisantes** : les bases officielles (EUIPO, INPI, WIPO/Madrid,
   Swissreg, TMview) **n'ont pas pu être interrogées** dans cet environnement (pas de navigateur ;
   API TMview HTTP 000 ; portails SPA). Conformément à la consigne, **aucune source officielle n'a
   été remplacée par un agrégateur** ; ces axes sont **MANUAL CHECK REQUIRED**. On **ne peut donc
   pas** affirmer l'absence de conflit marque — condition nécessaire au GO.

Un **signal contextuel** renforce la prudence : « Auren » est le nom d'un **réseau international
d'audit/conseil** (B2B), ce qui explique vraisemblablement le cluster domaine ancien. Sa classe
d'activité (conseil/audit, Nice ~35/36) semble **distincte** du logiciel fitness (9/42/44), mais la
notoriété d'un signe peut élargir sa protection — à trancher par un CPI.

**Conclusion** : le nom n'est ni manifestement rejetable (pas de conflit fitness/logiciel prouvé),
ni clairable en interne (marques non vérifiées + domaines saturés). → **transmission à un CPI**.
