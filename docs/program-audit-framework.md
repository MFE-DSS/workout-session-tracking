# Grille d'audit hypertrophie SPIGNOS

Cadre d'evaluation pour programmes de musculation orientes hypertrophie.
Cible : pratiquant intermediaire naturel.

---

## Section 1 : Checklist d'audit rapide

Parcourir en 2 minutes. Chaque "non" = drapeau rouge a investiguer.

| # | Question | O/N |
|---|----------|-----|
| 1 | Chaque groupe musculaire recoit-il >= 10 series/semaine ? | |
| 2 | Aucun groupe ne depasse 20-25 series/semaine ? | |
| 3 | Chaque muscle est-il stimule >= 2x/semaine ? | |
| 4 | Les exercices composes sont-ils places en debut de seance ? | |
| 5 | L'isolation vient-elle apres les composes dans chaque seance ? | |
| 6 | Chaque seance dure-t-elle <= 75 min (hors cardio) ? | |
| 7 | Y a-t-il un mouvement en etirement (lengthened) par groupe majeur ? | |
| 8 | Les plages de reps varient-elles (6-10, 8-12, 10-15, 12-20) ? | |
| 9 | Le programme prevoit-il une surcharge progressive explicite ? | |
| 10 | Les seances consecutives evitent-elles de fatiguer les memes muscles ? | |
| 11 | Les delts posterieurs et lateraux sont-ils explicitement couverts ? | |
| 12 | Les mollets/tibiaux anterieurs sont-ils programmes ? | |
| 13 | Le core est-il travaille (au moins 6 series/semaine) ? | |
| 14 | Le tempo excentrique est-il specifie (2-3s) ? | |
| 15 | Le repos inter-series est-il indique (90-150s) ? | |
| 16 | Les techniques d'intensite (RP, DS) sont-elles utilisees avec parcimonie ? | |
| 17 | Le programme est-il reproductible semaine apres semaine ? | |
| 18 | Aucun exercice n'est-il redondant sans justification ? | |
| 19 | Le rapport push/pull est-il equilibre (~1:1 en volume) ? | |
| 20 | Le programme est-il realisable en salle commerciale standard ? | |

**Interpretation** : 18-20 oui = excellent, 15-17 = correct avec reserves, < 15 = revision necessaire.

## Section 2 : Grille de notation (1-5)

### Critere 1 : Qualite hypertrophique (stimulus musculaire total)

| Note | Description |
|------|-------------|
| 1 | Volume < 6 series/muscle/semaine ou absence de groupes entiers |
| 2 | Volume insuffisant sur plusieurs groupes (< 10 series) ou frequence 1x |
| 3 | Volume dans les landmarks pour les grands groupes, mais petits muscles negliges |
| 4 | Volume 10-20 series/muscle/semaine, tous les groupes couverts, frequence >= 2x |
| 5 | Volume optimal par groupe, variation des angles/longueurs, frequence 2-3x, techniques d'intensification bien placees |

**Niveau de preuve** : [Fortement soutenu] -- Schoenfeld 2017, meta-analyse dose-reponse volume.

### Critere 2 : Ratio stimulus/fatigue (efficacite)

| Note | Description |
|------|-------------|
| 1 | Exercices a fatigue systemique elevee sans justification (deadlifts lourds + squats le meme jour) |
| 2 | Plusieurs exercices a fatigue elevee par seance, pas de machine/cable |
| 3 | Mix raisonnable mais 1-2 choix sous-optimaux (ex: barbell row lourd apres deadlift) |
| 4 | Majorite machines/cables pour isolation, barres libres uniquement ou justifie |
| 5 | Chaque exercice maximise le stimulus pour le muscle cible avec fatigue systemique minimale. Machines et cables dominent sauf mouvement compose cle |

**Niveau de preuve** : [Probable] -- Concept SFR (Israetel), pas de meta-analyse directe.

### Critere 3 : Coherence de l'ordre des exercices (intra-seance)

| Note | Description |
|------|-------------|
| 1 | Isolation avant composes, aucune logique d'enchaînement |
| 2 | Ordre partiellement coherent mais des erreurs flagrantes |
| 3 | Composes d'abord, puis isolation, mais angles/muscles non optimises |
| 4 | Compose lourd -> compose moyen -> isolation, coherent pour le groupe cible |
| 5 | Ordre optimal : compose lourd (6-10) -> compose moderee (8-12) -> isolation (10-15+), muscles synergistes places apres les agonistes, pre-fatigue justifiee si utilisee |

**Niveau de preuve** : [Fortement soutenu] -- Simao et al. 2012, effet de l'ordre sur la performance.

### Critere 4 : Coherence de la semaine (inter-seances)

| Note | Description |
|------|-------------|
| 1 | Meme muscle travaille 2 jours consecutifs sans repos, collision de fatigue constante |
| 2 | Collisions de fatigue frequentes (ex: dos lourd puis pull le lendemain) |
| 3 | Structure globale correcte mais 1-2 conflits de recupération |
| 4 | Split bien concu, 48-72h entre stimulations du meme groupe, alternance coherente |
| 5 | Agencement optimal : synergistes/agonistes groupes logiquement, pas de collision de fatigue, jours de repos bien places |

**Niveau de preuve** : [Probable] -- Derives des recommandations de frequence (Schoenfeld & Grgic 2018).

### Critere 5 : Qualite du choix des exercices (selection)

| Note | Description |
|------|-------------|
| 1 | Exercices generiques sans ciblage, redondances majeures |
| 2 | Bons exercices mais mauvaise couverture des angles/portions musculaires |
| 3 | Couverture correcte des groupes principaux, manque sur les portions specifiques |
| 4 | Bonne variete d'angles, positions en etirement incluses, portions musculaires ciblees |
| 5 | Selection optimale : chaque muscle couvert en position etiree ET raccourcie, variete de prises, mouvements unilateraux presents, redondance zero |

**Niveau de preuve** : [Fortement soutenu] pour etirement (Pedrosa et al. 2023 lengthened partials), [Inference pratique] pour le reste.

### Critere 6 : Qualite de la progression (protocole)

| Note | Description |
|------|-------------|
| 1 | Aucun protocole de progression defini |
| 2 | "Augmenter la charge quand c'est facile" sans cadre |
| 3 | Plages de reps definies mais sans mecanisme de progression explicite |
| 4 | Double progression (reps puis charge) avec plages claires |
| 5 | Double progression explicite + criteres de montee en charge + gestion du plateau (deload, changement d'exercice) + tempo prescrit |

**Niveau de preuve** : [Fortement soutenu] -- Principe de surcharge progressive (Kraemer & Ratamess 2004).

### Critere 7 : Compatibilite pratiquant intermediaire naturel

| Note | Description |
|------|-------------|
| 1 | Volume/frequence de bodybuilder assiste, > 25 series/muscle, 6x/semaine |
| 2 | Volume trop eleve pour un naturel, recuperation impossible |
| 3 | Globalement adapte mais certains muscles surcharges |
| 4 | Volume et frequence adaptes, recupération realiste, seances <= 75 min |
| 5 | Parfaitement calibre : 10-20 series/muscle/semaine, 4-5 seances/semaine, seances 45-75 min, jours de repos suffisants, deload prevu |

**Niveau de preuve** : [Probable] -- Helms et al. 2014, recommandations naturels; [Inference pratique] pour les seuils exacts.

## Section 3 : Detection des anti-patterns

| # | Symptome observable | Cause probable | Impact sur les gains | Correction prioritaire |
|---|---------------------|----------------|----------------------|------------------------|
| 1 | Plus de 8 exercices par seance regulierement | Volume mal reparti ou exercices inutiles | Fatigue centrale, qualite en chute sur les derniers exos | Supprimer les redondances, redistribuer sur la semaine |
| 2 | Meme exercice dans 2 seances differentes sans raison | Split mal concu, manque de variete | Stimulus identique, volume gaspille | Varier l'angle ou la prise entre les variantes A/B |
| 3 | Aucun mouvement en position etiree pour un muscle | Choix d'exercices par habitude | Perte de ~30% du stimulus potentiel (Pedrosa 2023) | Ajouter un mouvement lengthened (incline curl, fly, RDL) |
| 4 | Tous les exercices dans la meme plage de reps | Absence de periodisation de l'intensite | Sous-stimulation des unites motrices a seuil eleve/bas | Repartir : 6-10 (compose), 8-12 (moderee), 10-15+ (isolation) |
| 5 | Isolation avant compose dans la seance | Ordre irreflechi | Performance reduite sur le compose, volume effectif perdu | Deplacer les composes en debut de seance |
| 6 | Quadriceps sans ischios (ou inversement) | Split desequilibre | Risque blessure, desequilibre esthetique | Ajouter le mouvement antagoniste |
| 7 | Delts lateraux < 6 series/semaine | Sous-estimation de ce muscle | "Epaules etroites" malgre un bon physique general | Ajouter laterales cable/halteres, 12-20 reps |
| 8 | Pas de mollets dans le programme | "Les squats suffisent" (faux) | Mollets en retard permanent | 6-8 series/semaine, debout + assis |
| 9 | Techniques RP/DS sur les composes lourds | Mauvaise application des techniques | Risque de blessure, fatigue systemique explosive | Reserver RP/DS aux isolations et machines |
| 10 | Seance > 90 min regulierement | Trop de volume ou repos trop longs | Cortisol eleve, qualite en baisse, adherence menacee | Couper du volume ou reorganiser le split |
| 11 | Push/Pull desequilibre (ex: 2 push pour 1 pull) | Split asymetrique | Desequilibre postural, epaules en rotation interne | Egaliser le volume push et pull |
| 12 | Meme muscle frappe 2 jours de suite | Planning mal agence | Recuperation insuffisante, performance degradee | Inserer 48-72h minimum entre stimulations |
| 13 | Aucun mouvement unilateral | Oubli ou paresse | Desequilibres lateraux non corriges | Ajouter 1 exercice unilateral par grand groupe |
| 14 | Pas de face pull / rear delt | Negligence du deltoide posterieur | Sante de l'epaule compromise, esthetique 3D manquante | 3-6 series/semaine rear delts obligatoire |
| 15 | Seuls des halteres utilises (pas de cable/machine) | Dogme "free weights only" | SFR sous-optimal, fatigue systemique inutile | Introduire machines pour isolation, cables pour tension continue |

## Section 5 : Audit du catalogue SPIGNOS v4

### Vue d'ensemble du catalogue

15 modules, 3 familles de split :

| Famille | Modules | Frequence cible |
|---------|---------|-----------------|
| PPL (Push/Pull/Legs) | push-a, push-b, pull-a, pull-b, legs-a, legs-b | 6 seances/semaine (PPL x2) |
| Upper/Lower | upper-pecs-delts, upper-back-arms, lower-quad-bias, lower-posterior-bias | 4 seances/semaine (U/L x2) |

### Synthese de l'audit SPIGNOS v4

**33/35** -- Le catalogue est science-based, bien equilibre et adapte a la population cible. Les deux points perdus relevent de la couche "meta" (deload, agencement hebdomadaire) qui depasse le scope d'un catalogue de templates. Aucun defaut structurel dans les exercices, l'ordre ou le volume.

## Section 6 : Garde-fous scientifiques

Regles non-negociables que tout audit doit verifier. Un programme qui viole l'une de ces regles est disqualifie.

### 6.1 Volume dans les landmarks

| Regle | Seuil | Source |
|-------|-------|--------|
| Volume minimum par muscle | >= 10 series/semaine | [Fortement soutenu] Schoenfeld et al. 2017 |
| Volume maximum par muscle | <= 20-25 series/semaine | [Fortement soutenu] meta-analyses dose-reponse |
| Volume par seance par muscle | <= 10 series | [Probable] rendements decroissants au-dela (Israetel) |

### 6.2 Pas de muscle oublie

Groupes qui doivent tous apparaitre explicitement :

- Pectoraux (faisceau claviculaire + sternal)
- Dos largeur (grand dorsal) + epaisseur (rhomboïdes, trapezes moyens)
- Deltoides : anterieur, lateral, posterieur (les 3)
- Biceps (long chef + court chef)
- Triceps (long chef + chefs lateral/medial)
- Quadriceps
- Ischio-jambiers
- Fessiers (au minimum indirect)
- Mollets (gastrocnemien + soleaire = debout + assis)
- Core (au moins 6 series/semaine)

**Niveau de preuve** : [Inference pratique] -- Consensus coaching, pas d'etude sur les muscles "oublies".

### 6.3 Pas de collision fatigue

| Regle | Description |
|-------|-------------|
| 48h minimum | Entre deux stimulations directes du meme muscle |
| Pas de push apres push | Pas deux seances push consecutives |
| Pas de legs apres legs | Idem |
| Synergistes | Considerer que les triceps travaillent sur les push, les biceps sur les pull |

**Niveau de preuve** : [Fortement soutenu] -- Recommandations ACSM, Ratamess et al. 2009.

### 6.4 Progression plausible

| Regle | Description |
|-------|-------------|
| Double progression | Plages de reps definies, montee en charge quand borne haute atteinte |
| Deload prevu | Toutes les 4-6 semaines ou sur signaux (stagnation, fatigue) |
| Pas de progression lineaire indefinie | Un naturel intermediaire ne peut pas ajouter du poids chaque semaine |

**Niveau de preuve** : [Fortement soutenu] -- Principe de surcharge progressive, unanimement soutenu.

### 6.5 Duree realiste

| Regle | Seuil |
|-------|-------|
| Seance de musculation | 45-75 min (hors echauffement et cardio) |
| Nombre d'exercices | 5-8 par seance |
| Series totales par seance | 15-25 |
| Frequence hebdomadaire | 3-6 seances (4-5 optimal pour un intermediaire naturel) |

**Niveau de preuve** : [Probable] -- Derives des recommandations de duree et volume, pas de seuil exact valide experimentalement.

### 6.6 Frequence suffisante

| Regle | Seuil | Source |
|-------|-------|--------|
| Frequence minimum par muscle | 2x/semaine | [Fortement soutenu] Schoenfeld et al. 2016, meta-analyse frequence |
| Frequence optimale | 2-3x/semaine | [Fortement soutenu] meme meta-analyse |
| Au-dela de 3x | Rendements marginaux, complexite accrue | [Probable] |

## Legende des niveaux de preuve

| Tag | Signification |
|-----|---------------|
| **[Fortement soutenu]** | Meta-analyse ou revue systematique publiee, consensus scientifique |
| **[Probable]** | Etudes multiples convergentes, pas de meta-analyse ou resultats mixtes |
| **[Inference pratique]** | Derive logique de principes soutenus, consensus coaching, pas de preuve directe |
