4. Réglage non massique/assistance/par-implément préservé ; vieux réglage seulement avec reconfirmation réellement courante.
5. Bootstrap sans protocole ou temps initial complet : refus de READY.
6. Base empirique/convention de temps non admise, budget simplement large ou LIKELY_FITS expérimental : refus de READY.
7. Version/source/policy/subject/fingerprint/binding divergents ou révoqués : refus ; bool/int/float distincts.
8. Même observation réordonnée : rejeu stable ; fait changé : empreinte complète changée ; aucune donnée cachée.
9. Faux registre ou fixture d'exemple : jamais autorité ; positif seulement avec vraies décisions/gates.
10. Handoff absent : plan éventuel ≠ séance créée ; runtime PLAN et recette physique séparés.
